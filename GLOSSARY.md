# Конструктор учебных сценариев

Сценарий — набор переиспользуемых шагов, который проходится в разных режимах, журналируется и оценивается независимыми анализаторами.

## Структура сценария

**Step (шаг)**:
Переиспользуемое задание с идентификатором, условиями выполнения и условиями нарушения. Один и тот же шаг входит в план любого режима без копирования.
_Avoid_: задание, task, action

**Action Source (источник действия)**:
Объект сцены, который сообщает об одном конкретном действии пользователя: нажатии кнопки, входе в триггер, столкновении, вызове события.
_Avoid_: trigger (это частный случай), event source, sensor

**Context Condition (контекстное условие)**:
Требование к состоянию другого объекта сцены, без которого действие шага считается нарушением.
_Avoid_: requirement, precondition

**Stage (этап)**:
Набор шагов, активных одновременно. Следующий этап открывается, когда все шаги текущего завершены.
_Avoid_: batch, phase, пакет

**Group (группа)**:
Последовательность этапов со своим порогом нарушений. Достижение порога пропускает незавершённые шаги группы.
_Avoid_: section, block

## Прохождение

**Mode (режим)**:
План прохождения тех же шагов: разбиение на группы и этапы плюс правила обработки нарушений. Режим — это настройка, а не отдельная логика.
_Avoid_: run mode, profile

**Run (прохождение)**:
Один запуск сценария в выбранном режиме от начала до конца.
_Avoid_: session, playthrough

**Violation (нарушение)**:
Действие, которое шаг считает ошибкой: запрещённое действие, неверный порядок, невыполненное контекстное условие или действие вне очереди.
_Avoid_: error, mistake, ошибка

**Out-of-turn Action (действие вне очереди)**:
Действие, относящееся к шагу, который ещё не активен. Засчитывается самому раннему незавершённому шагу с этим источником.
_Avoid_: premature action

**Attempt (попытка)**:
Порядковый номер попытки выполнить шаг: один плюс число нарушений этого шага.
_Avoid_: try, retry

**Step Status (статус шага)**:
Итог шага в прохождении: Completed, Failed или Skipped.
_Avoid_: state, result

## Анализ

**Log (журнал)**:
Упорядоченные записи о событиях одного прохождения. Единственный источник данных для анализа.
_Avoid_: history, trace

**Analyzer (анализатор)**:
Алгоритм оценки, который по журналу вычисляет баллы и предупреждения, не зная режима и исполнителя.
_Avoid_: scorer, evaluator, grader
